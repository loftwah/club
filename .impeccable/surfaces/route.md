# Homepage surface brief

Mode: Persuade.

Audience: a first-time visitor who wants belonging and recognition without attendance or social performance.

Job: understand the unusual mechanism within seconds, trust that cancellation is intentional fulfilment, compare the relationship tiers and register interest.

Primary action: join the waiting list. Proof must come from a fully legible invitation lifecycle, truthful policy and real or explicitly labelled example data—not fabricated activity.

Chosen direction: Dispatch Wall. The page behaves like a contemporary operations strip bay: a plan is inserted, becomes present as the date approaches, receives a decisive successful cancellation marker, then settles into accumulated history. Correspondence introduces the warmer second material world.

Approved comp: `.impeccable/mocks/home-dispatch-wall.png`.

Memorable moment: one invitation strip becomes deliberately cancelled without turning into an error, after which the composition physically opens and relaxes.

Component grammar: cool paper fields, near-black data, electric cobalt registration/active marks, vermilion cancellation fields; square-to-small-radius controls; hairline rules; perforations and rails only where they carry state; no generic card grid.

Type grammar: compressed, characterful sans display; workhorse sans body; tabular condensed date/status face. Headline is large but capped below 6rem; scheduling data is treated as graphic material.

Implementation inventory:

| Ingredient                   | Medium                                              | Commitment                                                |
| ---------------------------- | --------------------------------------------------- | --------------------------------------------------------- |
| Navigation                   | Semantic Astro + Lucide                             | Compact, responsive, no horizontal overflow               |
| Headline and waitlist action | Semantic HTML/CSS                                   | Visible in first viewport; no baked text                  |
| Invitation strip             | Semantic HTML/CSS                                   | Full readable event type/date/time/chapter/status         |
| Schedule bay/rail            | CSS geometry                                        | Occupies most of first viewport; no decorative card shell |
| Cancellation transition      | CSS/Motion; optional ThreeUI after benchmark        | Same object changes state; cancellation is success        |
| Reduced/mobile variant       | Semantic HTML/CSS                                   | Beautiful composed end state, no cheap fallback           |
| Correspondence continuation  | HTML/CSS plus approved raster only if required      | World 2 supports, never dominates                         |
| Functional icons             | Lucide Astro/React                                  | Consistent stroke; not brand identity                     |
| Paper material               | CSS colour and restrained texture asset if approved | No faux heritage or wax motifs                            |

Constraints: no RSVP/check-in/attendance language; no fake counters, partnerships or bookings; no implementation or provider terminology in reader-facing copy; no essential WebGL; payments remain disabled; performance and WCAG 2.2 AA targets apply.
