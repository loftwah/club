# Asset pipeline

## Source classes

- `public/brand/` contains production raster/SVG assets.
- `public/og/` contains deterministic social SVGs generated by
  `scripts/og-generate.mjs`.
- `explorations/brand/` and public exploration mirrors are historical visual
  research, protected on deployed hosts and not production identity.
- `.impeccable/mocks/` contains project-bound north-star compositions and
  prompt/decision sidecars. Raster UI from these comps is never shipped.

## Build path

`scripts/clean-build-output.mjs` removes only generated `dist/` and
`public/_astro/`. Astro builds fresh hashed assets, then
`scripts/copy-assets.mjs` copies the new `_astro` directory for Wrangler's
public-assets binding. This prevents stale bundles from surviving a new build.

The performance checker warns above 350 KiB per viewport image and can make
that threshold strict. Production images must declare dimensions; viewport
imagery should use responsive candidates and AVIF/WebP where it produces a
meaningful reduction. An exploration/archive original is not automatically a
viewport candidate.

## Social cards

Social assets are programmatic 1200×630 SVGs using real text, schedule grids and
the labelled illustrative cancellation object. They do not use generated image
text. `src/lib/og.ts` provides dynamic chapter/article variants; the Node
generator produces the committed default templates.

Run:

```sh
node scripts/og-generate.mjs
pnpm build
pnpm perf:budget
```

Inspect every generated template at 1200×630 before release. No headline may
clip, and no OG image may imply a real venue, booking, partnership or statistic.
